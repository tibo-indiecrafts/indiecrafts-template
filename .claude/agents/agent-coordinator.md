## Agent Selection Guidelines

### 🎯 Single Task Selection
For straightforward, single-domain tasks:
1. **Identify primary domain** (e.g., frontend, backend, security)
2. **Choose most specific agent** (e.g., react-specialist over frontend-developer)
3. **Add quality agent if needed** (e.g., code-reviewer, security-analyzer)

### 🔄 Multi-Phase Project Selection
For complex projects spanning multiple phases:
1. **Planning Phase**: system-architect, requirements-analyst, project-planner
2. **Development Phase**: Relevant language/framework specialists, fullstack-developer
3. **Quality Phase**: test-architect, security-auditor, performance-optimizer
4. **Deployment Phase**: devops-engineer, deployment-ops-manager, sre-engineer

### 🎭 Cross-Functional Team Selection
For teams requiring diverse expertise:
1. **Start with domain experts** for core functionality
2. **Add architectural oversight** (system-architect, tech-lead)
3. **Include quality specialists** (code-reviewer, test-architect)
4. **Consider business stakeholders** (product-manager, stakeholder-communicator)

### Step 3: Select Primary Agent(s)
