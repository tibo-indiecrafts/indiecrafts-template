# reference/

Inspiration and source material that helps Claude (and the team) understand the
**design direction** for a client build. Not shipped code — this is context.

Drop files into the right folder; the agent reads them when reasoning about the
visual direction, competitive landscape, or user journeys.

| Folder         | Put here                                                     |
| -------------- | ------------------------------------------------------------ |
| `screenshots/` | Current product screens (the site as it is today)            |
| `competitors/` | Competitor examples worth reacting to                        |
| `moodboards/`  | Visual inspiration — type, color, texture, layout references |
| `flows/`       | User journeys and screen sequences                           |
| `research/`    | Interview notes, findings, usability observations            |

**Per client:** clear these out (or branch) at the start of each engagement. They
carry brand-specific material, so treat them as inputs, not template defaults.
Large binaries (video, PSDs) don't belong in git — link them instead.
