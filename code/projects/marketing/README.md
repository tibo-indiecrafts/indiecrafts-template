# @indiecrafts/marketing

Reserved slot for a **separate Next.js marketing site** (campaigns · landing pages · microsites), apart
from the product app (`web`). Same stack (Next 16 · React 19 · Tailwind v4), its own config + deploy.

**Status: skeleton** — no app yet. Activate: `pnpm create next-app code/projects/marketing`, then wire the
shared bricks + its own `src/config` (see `.claude/CLAUDE.md` and `docs/apps/web/config/multi-app.md`).
