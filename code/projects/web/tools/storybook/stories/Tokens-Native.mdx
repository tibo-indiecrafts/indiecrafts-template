# Native tokens (hex)

The **same** design tokens as web, resolved to hex for React Native. Web CSS variables
(`--background`, …) and these hex values are **both generated** from the one source —
`code/packages/shared/ui-tokens/src/shared/tokens.json` (DTCG, OKLCH) — by
`pnpm tokens:build`. The mobile app reads them from
`@indiecrafts/packages-shared-ui-tokens/native`; the `ui-native` brick + `system-pages/native`
paint from these. RN has no live theme variable, so both light and dark are shown side by side.
