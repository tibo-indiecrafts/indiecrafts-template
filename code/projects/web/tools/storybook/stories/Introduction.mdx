# indiecrafts design system

Live documentation for the design-system packages. Flip **light / dark** with the theme toolbar
(top bar) — it sets `data-theme`, so tokens, components, code blocks, and prose all invert together.

## Packages

- **`@indiecrafts/packages-web-ui-tokens`** — the source of truth: OKLCH color roles, radius, typography
  (`globals.css` + `typeset.css`). The visual contract is `code/packages/web/ui-tokens/DESIGN.md`.
- **`@indiecrafts/packages-web-ui`** — 61 shadcn/ui primitives (Button, Card, Dialog, Form…). CLI-managed;
  styled entirely by the tokens. See **UI** in the sidebar. Each primitive keeps a colocated `.md` usage doc.
- **`@indiecrafts/packages-web-ui-components`** — the page-builder block renderers (Callout, CardList,
  Gallery, CodeBlock…) shared by the app and the blog. See **UI Components** in the sidebar.
- **`@indiecrafts/packages-web-system-pages`** — the branded status pages (404 · error · offline ·
  maintenance). See **System Pages**.
- **`@indiecrafts/packages-web-ui-icons`** — the icon system (`Icon`, `BrandIcon`, `SvgIcon`,
  `ReiconIcon`). See **Icons**.

## How the stories are organized

Stories live **next to their component** in each package (`button.stories.tsx` beside
`button.tsx`), so docs never drift from source. This Storybook package only aggregates them.

> When you add or change a component, add or update its story in the same change.
