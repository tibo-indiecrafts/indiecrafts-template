# indiecrafts design system

Live documentation for the design-system packages, across **all three renderers** — web (DOM),
native (React Native, rendered here via react-native-web), and the cross-platform pages shared by
both. Flip **light / dark** with the theme toolbar (top bar) — web keys on `data-theme`, native on
its `ThemeProvider` + `Appearance`, so tokens, components, code blocks, and prose all invert together.

## Packages

- **`@indiecrafts/packages-shared-ui-tokens`** — the source of truth: OKLCH color roles, radius, typography
  (`globals.css` + `typeset.css`), with the **native (hex)** mirror under **Design Tokens → Native**. The
  visual contract is `code/packages/ui-tokens/DESIGN.md`.
- **`@indiecrafts/packages-web-ui`** — 61 shadcn/ui primitives (Button, Card, Dialog, Form…). CLI-managed;
  styled entirely by the tokens. See **UI** in the sidebar. Each primitive keeps a colocated `.md` usage doc.
- **`@indiecrafts/packages-web-ui-components`** — the page-builder block renderers (Callout, CardList,
  Gallery, CodeBlock…) shared by the app and the blog. See **UI Components** in the sidebar.
- **`@indiecrafts/packages-mobile-ui-native`** — the React Native design system (`Screen`, `ThemedText`,
  `Button`, `Card`) over the shared tokens. See **Native** in the sidebar.
- **`@indiecrafts/packages-shared-system-pages`** — the branded status pages (404 · error · offline ·
  maintenance), forked **web + native**. See **System Pages**.
- **`@indiecrafts/packages-shared-ui-icons`** — the icon system (`Icon`, `BrandIcon`, `SvgIcon`,
  `ReiconIcon`), web renderers today. See **Icons**.

## How the stories are organized

Stories live **next to their component** in each package (`button.stories.tsx` beside
`button.tsx`), so docs never drift from source. This Storybook package only aggregates them.

> When you add or change a component, add or update its story in the same change.
