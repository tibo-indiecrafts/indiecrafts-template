# Typography & radius

## Radius

One radius token, `--radius` (`0.5rem`), scales the shadcn `rounded-*` steps. Boxes below paint
`background: var(--muted)` with increasing `border-radius`.

<div style={{ display: "flex", gap: "1rem", alignItems: "flex-end", margin: "1.25rem 0" }}>
  {[
    ["calc(var(--radius) - 4px)", "sm"],
    ["calc(var(--radius) - 2px)", "md"],
    ["var(--radius)", "base"],
    ["calc(var(--radius) + 4px)", "lg"],
    ["9999px", "full"],
  ].map(([r, label]) => (
    <div key={label} style={{ textAlign: "center" }}>
      <div style={{ width: 72, height: 72, background: "var(--muted)", borderRadius: r, boxShadow: "inset 0 0 0 1px var(--border)" }} />
      <code style={{ fontSize: 12 }}>{label}</code>
    </div>
  ))}
</div>

## Typeset (long-form prose)

`typeset.css` styles long-form content via `.typeset-docs` — headings, paragraphs, lists, inline
`code`, and block code — all pulling theme tokens, so it flips light/dark automatically.

<div className="typeset-docs" style={{ maxWidth: "68ch", marginTop: "1.25rem" }}>

  </p>

</div>
