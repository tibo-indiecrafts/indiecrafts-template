# `@indiecrafts/packages-web-i18n` — shared navigation shim

A thin next-intl navigation layer so **modules** get `Link`/nav without importing the app.

|               |                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exports**   | `.` → `src/index.ts` — `routing` (from `defineRouting` off config's `localeCodes`/`i18n`), an **untyped** `createNavigation` (`Link` · `redirect` · `usePathname` · `useRouter` · `getPathname`), **`useLocaleSwitch`** (the shared locale-switch hook — next-intl prefix swap + the blog translated-slug resolve; used by the header `LocaleSwitcher` **and** `@indiecrafts/packages-web-locale-suggest`), plus a re-export of `localizedPathname` |
| **Deps**      | `@indiecrafts/packages-shared-config`, `next-intl ^4`. **Peer:** `next 16.3.1`, `react 19.2.8`                                                                                                                                                                                                                                                                                                                                                      |
| **Consumers** | blog module (the app keeps its own typed routing)                                                                                                                                                                                                                                                                                                                                                                                                   |

- **Gotcha — untyped on purpose.** The app does **not** use this; it keeps typed routing
  in `src/i18n/routing.ts` (with `PATHNAMES` built from app routes). Modules use this shim
  for their links; app-owned pathnames stay typed. This brick exists to break the old
  inversion where the blog imported `@/i18n/routing` (which points _up_).
