# Locale configuration

> The languages the site ships and the helpers derived from them.

## Purpose

Declares the languages the site ships, the unprefixed default, how locales appear in URLs, and the derived lookups. `i18n/routing.ts` and the proxy consume `i18n` directly; the flat aliases are the stable public API. Adding a language means adding a row to `i18n.locales` and dropping `messages/<code>.json`.

## Exports

- `i18n` — the config object: `locales`, `defaultLocale`, `localePrefix`, `localeDetection`.
- `locales`, `defaultLocale`, `localeCodes`, `localeMap` — flat aliases and O(1) lookups.
- `localePrefix(code)` — the URL path prefix for a locale, honouring the prefix policy.
- `localizedPathname(pathname, locale)` — a locale-aware absolute path for a dynamic route.
- `localeDir(code)` — text direction, falling back to `"ltr"`.
- `isLocale(value, supported)` — a locale type-guard.
- `toSiteLocale(value)` — a client-sent language (a form's page language, a cookie) as a site locale, else `defaultLocale`.
- `localeCopy(table, locale)` — built-in copy for `locale`: its own, else the default locale's, else English (the order `pickLocale` uses for Studio copy).
- `pickSuggestedLocale(rankedPrefs, active, supported)` — the first ranked preference that differs from the active locale, or `null`.
- `pickLocale(value, locale, fallback?)` — resolve a per-locale field (a `{ [code]: string }` object or a plain string) to one string.

## Usage

```ts
import {
  pickLocale,
  isLocale,
  localeCodes,
} from "@indiecrafts/packages-shared-config";

const title = pickLocale({ en: "Home", fr: "Accueil" }, "fr");
```
