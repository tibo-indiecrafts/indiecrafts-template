# Native theme tokens

> Generated hex design tokens for React Native.

## Purpose

The React Native token map. React Native has no CSS or `oklch`, so every color token is emitted as hex per light and dark, ready for `StyleSheet`. The file is generated by `scripts/build-tokens.mjs` from the token source; never hand-edit it (`pnpm tokens:check` fails if it drifts).

## Exports

- `tokens` — the `light` and `dark` theme records, each with a `color` map (token name to hex) and a numeric `radius`.
- `ThemeName` — the union of theme keys (`"light"` or `"dark"`).
- `ColorToken` — the union of color token names.

## Usage

```ts
import {
  tokens,
  type ColorToken,
} from "@indiecrafts/packages-shared-ui-tokens/native";

const brand = tokens.light.color.brand; // "#296cd8"
```
