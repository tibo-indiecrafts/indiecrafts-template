# Hex color mirror

> Generated hex colors for the PWA manifest.

## Purpose

A small hex mirror of the core theme colors, per light and dark. The PWA manifest (`app/manifest.ts`) cannot use `oklch`, so it reads these hex values, which `@/config` re-exports. The file is generated by `scripts/build-tokens.mjs` from the token source; never hand-edit it (`pnpm tokens:check` fails if it drifts).

## Exports

- `hexColors` — the `light` and `dark` records of core theme colors (`background`, `foreground`, `brand`) as hex strings.

## Usage

```ts
import { hexColors } from "@indiecrafts/packages-shared-ui-tokens/hex";

const themeColor = hexColors.dark.brand; // "#67a3ff"
```
