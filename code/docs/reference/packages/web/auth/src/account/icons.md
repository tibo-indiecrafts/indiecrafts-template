# Account widget icons

> Icons for the custom pages in Clerk's account widget.

## Purpose

Inline SVG icons passed to Clerk as each custom page's `labelIcon`: 16px, `currentColor` stroke, `aria-hidden` (the page label names the tab).

## Exports

- `ShieldIcon` — "Privacy & consent".
- `MailIcon` — "Emails".
- `GlobeIcon` — "Language".
- `DataIcon` — "Your data".
