# Callout module

> A coloured note box with rich content and an optional call-to-action.

## Purpose

Defines the `module.callout` block: a variant (`info`, `success`, `warning`, or `danger`), required rich `blockContent`, and an optional `cta`. Used to highlight a short passage inside a page.

## Exports

- `default` — the `module.callout` schema built with `defineModule`.
