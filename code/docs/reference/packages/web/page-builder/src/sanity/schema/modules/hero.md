# Hero module

> The lead band at the top of a marketing page.

## Purpose

Defines the `module.hero` block: an optional eyebrow, a required title (wrap a word in `[[ ]]` for the accent colour), an optional subtitle, and an optional `cta` button. Rendered by `Hero` in `@indiecrafts/packages-web-ui-components/web/layout`.

## Exports

- `default` — the `module.hero` schema built with `defineModule`.
