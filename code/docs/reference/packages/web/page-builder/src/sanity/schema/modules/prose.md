# Prose module

> A rich-text block with a width option.

## Purpose

Defines the `module.prose` block: required rich `blockContent` and a `width` option (`narrow` for article width, or `wide`). Used for long-form body copy inside a page.

## Exports

- `default` — the `module.prose` schema built with `defineModule`.
