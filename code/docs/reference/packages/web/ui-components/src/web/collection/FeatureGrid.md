# Feature grid

> A grid of icon feature cards.

## Purpose

Renders a `module.feature-grid` block: a centered title and intro over a grid of icon cards. Each card shows a token-coloured icon chip, a title, and a short body. It renders nothing with no items.

## Exports

- `FeatureGrid` — a centered title over a grid of icon feature cards.

## Usage

```tsx
import { FeatureGrid } from "@indiecrafts/packages-web-ui-components/web/collection/FeatureGrid";

<FeatureGrid {...module} />;
```
