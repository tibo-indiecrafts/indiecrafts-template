# Mobile 404 screen

> The catch-all 404 screen for unmatched mobile routes.

## Purpose

The Expo Router catch-all route. It renders the shared `NotFoundContent` from `system-pages/native` inside a themed `Screen`, with translated copy from `react-intl`. The home button replaces the route with `/`.

## Exports

- `default` — the `NotFound` screen component, rendered by Expo Router for unmatched paths.
