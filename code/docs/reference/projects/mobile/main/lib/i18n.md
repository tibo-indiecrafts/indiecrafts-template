# Mobile i18n

> The detect-and-format split for mobile localization.

## Purpose

Owns the mobile i18n detect-and-format split. `expo-localization` reads the device locale; `react-intl` formats. Locale vocabulary and the `flattenMessages` helper come from `@/config`; the shell copy comes from `system-pages`. This file owns the detect source, the stored-choice accessors, and the app's own screen copy.

## Exports

- `detectLocale()` — the device locale, narrowed to a supported `Locale` (else `defaultLocale`).
- `getStoredLocale()` — the stored locale choice, narrowed to a `Locale` (else `null`).
- `setStoredLocale(locale)` — persists the visitor's explicit locale choice.
- `messagesFor(locale)` — shared shell copy plus this app's screen copy, flattened for react-intl.

## Usage

```ts
import { detectLocale, messagesFor } from "@/lib/i18n";

const locale = detectLocale();
const messages = messagesFor(locale);
```
