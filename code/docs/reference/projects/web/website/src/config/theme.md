# Theme config

> The code-side design identity — manifest hex, container sizing, and light/dark availability.

## Purpose

This file holds the parts of the app's design identity that must live as code: `theme.hexColors` (the hex mirror of the `background` oklch token that the PWA manifest needs), the container `maxWidth`/`gutter`, and `themeConfig` (which color modes the site offers and whether it is locked to one). Color tokens themselves are oklch in `globals.css`; the hex mirror is generated by `pnpm tokens:build`. `themeConfig` is consumed via `@/lib/theme` to set next-themes props and decide whether the toggle renders.

## Exports

- `theme` — `hexColors` (manifest background mirror) and `container` sizing.
- `themeConfig` — theme availability: `light`, `dark`, and `forced`.

## Usage

```ts
import { theme, themeConfig } from "@/config";
```
