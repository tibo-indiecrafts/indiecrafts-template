# Build info

> Generated build metadata; the version-check baseline.

## Purpose

Build metadata for the `app` surface. The file is generated by `scripts/version.mjs` inside `build:cf`; the committed values are a placeholder stamped with real values at build time. `commit` is the version-check baseline that `UpdatePrompt` compares against `/api/version`.

## Exports

- `buildInfo` — a frozen object with `version`, `branch`, `commit`, and `buildTime`.

## Usage

```ts
import { buildInfo } from "@/lib/build-info";

const current = buildInfo.commit;
```
