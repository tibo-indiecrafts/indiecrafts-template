# ADR 0000 — Template

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Deciders:** `<names>`

## Context

State the problem and the forces. What is true today? What constraint or need
prompts a decision? Keep it factual — one idea per sentence.

## Decision

State the choice in one sentence, then the reasoning. Name the alternatives you
rejected and why.

## Consequences

List what this makes easier, what it makes harder, and what it commits us to.
Include the follow-up work and any known ceiling.
