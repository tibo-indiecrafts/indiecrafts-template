# @indiecrafts/api — HTTP API worker

Auto-loads under `code/apps/api/**`. A **bare Cloudflare Worker** (no Next/OpenNext) exposing an HTTP API. This file is the app's _how to code_; platform rules live in the root `CLAUDE.md`.

**Stack:** Cloudflare Workers (`workerd`) · TypeScript · wrangler 4. A thin deploy shell — business logic is imported from packages/modules, not written here.

## Structure

```
src/index.ts       entrypoint — `export default { fetch }`
wrangler.toml      per-env config (name · bindings · observability); `name = indiecrafts-api-<env>`
scripts/deploy.mjs guard (rename) + prod-confirm + `wrangler deploy --env <env>`
worker-configuration.d.ts   generated by `pnpm cf-typegen` (typed bindings)
```

## Critical rules (the NEVERs)

- NEVER put business logic here — import it from a `code/packages/<name>` or `code/modules/<name>` brick (`workspace:*`). This app is the **deploy shell** only.
- NEVER hand-edit the `indiecrafts-api-*` names in `wrangler.toml` — `pnpm project:rename <slug>` owns them; a staging/prod deploy is blocked until they differ (shared-account guard).
- NEVER expose a secret in `[vars]` or code — use `wrangler secret put … --env <env>` (local: `.dev.vars`, gitignored).
- ALWAYS run `pnpm cf-typegen` after changing bindings; `pnpm --filter @indiecrafts/api tsc` before shipping.

## Deploy

`pnpm deploy:api:<dev|staging|prod>` (one app) or `pnpm deploy:all:<env>` (every app). Bare `wrangler deploy` bundles `src/` + imports — no build step. Edge config (WAF/cache/domain) → a Terraform dir under `code/infra/iac/cloudflare/apps/api/` (mirror web) + `infra:api:*` delegators, if this API needs a public domain.
