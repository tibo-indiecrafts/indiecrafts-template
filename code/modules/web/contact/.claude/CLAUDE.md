# Contact module — CLAUDE.md

**Stack:** Sanity v6 · TypeScript · `@indiecrafts/packages-web-sanity/write` (server-only) · `@indiecrafts/packages-web-email`. Contact form — submit engine + message inbox + settings singleton. Modeled on `@indiecrafts/modules-web-waitlist`.

Auto-loads under `code/modules/web/contact/**`. Feature-flagged by `features.contact` (app-owned in `@/config`, injected into the module). **Collect + notify** — every submission is stored and (best-effort) emailed; no dedupe (a person may write more than once).

- `src/lib/contact.ts` — the submit engine: validate → write (`writeClient`) a `contactMessage` (`status:"new"`). On a stored message, two **best-effort** emails may fire (never throw): a "we got your message" acknowledgement → the sender, and an owner alert **carrying the message** with `reply-to` set to the sender (hit Reply → answer the person). `submit()`. Feature-gating is the **app's** job: `/api/contact` gates on `features.contact`, `pages.contact.enabled` gates the `/contact` page, and `contactSanity(enabled)` hides the desk — the module reads no central flag.
- `src/lib/settings.ts` — `getContactSettings()` (React-`cache`d) reads the editor-configurable `contactSettings` singleton (form copy + `enabled`).
- `src/sanity/` — the `contactSettings` singleton + `contactMessage` doc + the "Contact" desk, exported as the `contactSanity(enabled)` **`SanityModule`** factory barrel (`src/sanity/index.ts`). Activate = one line — `contactSanity(features.contact)` in `appModules` (the `composeStudio([...])` call in `sanity.config.ts`); schema always registers, the desk hides when off. The message doc is **read-only** in Studio (API-written inbox, `status` is the one editable field).
- **Email config + copy** live on the shared `emailStrings` singleton (Studio → **E-mails**) — `contactConfirm` (translated) + `contactOwner`. Read via `getEmailStrings()` (narrow with `ConfirmationConfig`/`OwnerAlertConfig`); the only secret is `RESEND_API_KEY`. The **templates** (`contact-confirm` · `contact-notification`) live in `src/emails/`, rendering via `@indiecrafts/packages-web-email`.
- **Two public surfaces**, same `ContactForm` (POSTs `/api/contact` → `submit()`): a **full page** at `/contact` (`[locale]/contact/page.tsx`, registered in the `pages` map, copy from `contactSettings`) **and** a droppable **page-builder block** (`module.contact` schema in `@indiecrafts/packages-web-page-builder`, renderer in `@indiecrafts/packages-web-ui-components`, per-instance copy). `ContactForm`'s props are the copy subset (`ContactFormProps`) so both reuse it.
