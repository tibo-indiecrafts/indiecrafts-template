# AI assistant index (llms.txt) — fill-in form

Modern AI assistants (ChatGPT, Claude, Perplexity…) look for a small file that
summarises your site and points to key resources, so they can answer questions
about you accurately. Most of it is generated from your pages automatically —
you only need to confirm the summary and add any external links.

> 🌐 **Languages:** the summary and paragraph appear in each of your site's
> languages (English + French by default) — please provide them in **all** of
> them. External resource names/links are the same across languages.
