# 09_OUTPUTS — this feature's deliverables

Finished, curated work for **this feature** — promoted from the phases. Raw phase output
lands in gstack's `.gstack/`; the **keepers** land here, so the sprint folder holds the
whole story (brief → reference → phases → outputs) and its git log _is_ the history.

- Name `YYYY-MM-DD_<feature>_final.ext` (e.g. the shipped deliverable at `08_REFLECT`).
- Optional subfolders when it gets busy: `reviews/ qa/ design/ …` — the subfolder is the **kind**.
- **No sequence number, no `feat/fix` label** — `git log` is the order + the commit `type(scope):` is the type; record the **Source (PR/commit)** + kind in `work/DELIVERABLES.md`.
