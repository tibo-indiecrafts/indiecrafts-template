# 01_REFERENCE — inputs for THIS app

Inspiration + source material scoped to **this app**. Not shipped code — it's context
the agent reads when reasoning about direction. Feeds `00_BRIEF/` and the `04_BUILD` design
work, and lives with the sprint so its history travels with the app.

| Folder         | Put here                                          |
| -------------- | ------------------------------------------------- |
| `screenshots/` | Current screens of this app (as it is today)      |
| `competitors/` | Competitor examples worth reacting to             |
| `moodboards/`  | Visual inspiration — type, color, texture, layout |
| `flows/`       | User journeys and screen sequences                |
| `research/`    | Interview notes, findings, usability observations |

**Scope:** app-wide references here; feature-specific ones in that feature's own
`features/YYYY-MM-DD_<name>/01_REFERENCE/`.

**Per engagement:** clear or branch — brand-specific inputs, not template defaults.
Large binaries (video, PSDs) → link them, don't commit.
