# 09_OUTPUTS — this app's deliverables

Finished, curated work for **this app** — promoted from the phases. Raw phase output
lands in gstack's `.gstack/`; the **keepers** land here, so the sprint folder holds the
whole story (brief → reference → phases → outputs) and its git log _is_ the history.

- Name `YYYY-MM-DD_topic_final.ext`.
- Optional subfolders when it gets busy: `research/ design/ reviews/ qa/ retros/ …` — the subfolder is the **kind**.
- **No sequence number, no `feat/fix` label** — `git log` is the order + the commit `type(scope):` is the type; record the **Source (PR/commit)** + kind in `work/DELIVERABLES.md`.
- App-level artifacts here; feature deliverables in each `features/YYYY-MM-DD_<name>/09_OUTPUTS/`.
- Portfolio-level (cross-app) material stays in gstack global (`~/.gstack/`).
